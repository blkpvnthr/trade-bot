<objective>
## Goal

Add configurable time-of-day regime gating to `run.py` — session-aware buy sizing and
confirmation rules that encode professional intraday session discipline into the autonomous
execution loop.

## Purpose

Professional day traders treat the trading day as four distinct sessions:

- **09:30–11:30** — highest momentum and structure quality; full-size entries appropriate
- **11:30–13:00** — midday chop; liquidity thins, false moves increase, size should shrink
- **13:00–15:30** — institutional continuation; valid entries exist but require directional confirmation
- **15:30–16:00** — exit window; new risk is irrational this close to close

Without session awareness, the execution engine treats 14:50 the same as 09:45. The gate
closes that gap by reducing buy size, raising confidence requirements, or blocking new buys
depending on session — while leaving all exits, stop-losses, and risk controls completely
untouched.

    def _get_time_gate_session(now_et: datetime) -> TimeGateSession:
        """Return session window attributes for time-of-day gating. Buy path only."""
        if not TIME_OF_DAY_GATING_ENABLED:
            return TimeGateSession("morning", 1.0, 1.0, False)

        hhmm = now_et.hour * 100 + now_et.minute

        if _TOD_MORNING_START <= hhmm < _TOD_MORNING_END:
            return TimeGateSession("morning",   1.0,  1.0,  False)
        if _TOD_MIDDAY_START <= hhmm < _TOD_MIDDAY_END:
            return TimeGateSession("midday",    0.5,  1.25, False)
        if _TOD_AFTERNOON_START <= hhmm < _TOD_AFTERNOON_END:
            return TimeGateSession("afternoon", 1.0,  1.15, False)
        if _TOD_CLOSE_START <= hhmm < _TOD_CLOSE_END:
            return TimeGateSession("close",     0.0,  1.0,  True)
        return TimeGateSession("off_hours", 1.0, 1.0, False)
