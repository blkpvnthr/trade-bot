    ```
    import py_compile, re, sys
    from pathlib import Path

    PROJECT_ROOT = Path(__file__).resolve().parent.parent
    BUILDER  = PROJECT_ROOT / "build_intraday_training_dataset.py"
    FORECAST = PROJECT_ROOT / "forecast_engine.py"
    RL       = PROJECT_ROOT / "rl_intraday_structure_trainer.py"

    results: list[tuple[str, bool, str]] = []

    def check(name: str, passed: bool, detail: str = "") -> None:
        results.append((name, passed, detail))
        status = "[PASS]" if passed else "[FAIL]"
        print(f"{status} {name}" + (f": {detail}" if not passed else ""))
    ```

    **Check 1 — Builder→Forecast path suffix:**
    - Read BUILDER source text.
    - Find line matching `FEATURE_OUTPUT_PATH = .+ f"` and extract the suffix after DATA_TAG variable — expected: `_intraday_training_dataset.csv`
    - Read FORECAST source text.
    - Find line matching `INTRADAY_TRAIN_PATH = .+ f"` and extract suffix — expected: `_intraday_training_dataset.csv`
    - Use regex: `re.search(r'_intraday_training_dataset\.csv', builder_text)` and same for forecast.
    - check("path-align: builder→forecast", both match, diff detail if not)

    **Check 2 — Builder→RL path suffix:**
    - Same pattern but for `_intraday_bars_1m.csv` in BUILDER (RAW_OUTPUT_PATH line) and RL (first entry in the bars path list).
    - check("path-align: builder→rl_trainer", both match)

    **Check 3 — Log line in forecast_engine.py:**
    - check("log-line: forecast_engine [data-source]", "[data-source] training_csv=alpaca_derived" in forecast_text)

    **Check 4 — Log line in rl_intraday_structure_trainer.py:**
    - check("log-line: rl_trainer [data-source]", "[data-source] training_csv=alpaca_derived" in rl_text)

    **Check 5 — Feed log line in builder:**
    - check("log-line: builder [data-feed]", "[data-feed] regular=" in builder_text)

    **Check 6 — Compile: build_intraday_training_dataset.py:**
    - try py_compile.compile(str(BUILDER), doraise=True); check passes
    - except py_compile.PyCompileError as e: check fails with str(e)

    **Check 7 — Compile: forecast_engine.py:**
    - Same pattern for FORECAST

    **Check 8 — Compile: rl_intraday_structure_trainer.py:**
    - Same pattern for RL

    **Summary + exit:**
    ```
    passed = sum(1 for _, ok, _ in results if ok)
    total  = len(results)
    print()
    if passed == total:
        print(f"All {total} checks passed.")
        sys.exit(0)
    else:
        print(f"{total - passed}/{total} checks failed.")
        sys.exit(1)
    ```

    Avoid: importing forecast_engine, rl_intraday_structure_trainer, or build_intraday_training_dataset — they have heavy deps (torch, alpaca-py) and side effects on import.
    Do not require any env vars. Works without .env.
