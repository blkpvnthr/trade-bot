📈 One-time setup: install the Charting Library

The chart renderer is TradingView's gated (but free) Advanced Charts library — only you can fetch it:

  1. Apply at tradingview.com/charting-library (instant for non-commercial use).
  2. Download the bundle, then copy charting_library/ and datafeeds/ into /root/trade-bot/static/ on the server.
  3. Reload this page.

The data backend (/dash/udf) is already live and serving real bars + insider marks — only these front-end files are missing.
